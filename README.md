Retail Sales Analysis Internship Project

1. Project Overview

This project focuses on Retail Sales Analysis using Python. The main objective is to analyze retail sales data, understand customer purchasing behaviour, identify sales trends and generate meaningful business insights through data analysis and visualization.

This project was completed as part of my internship learning experience.

2. Project Objectives

- Clean and prepare raw retail sales data.
- Perform data transformation and exploratory data analysis (EDA).
- Analyze customer segments and purchasing behaviour.
- Identify repeat customers and customer purchasing patterns.
- Analyze top-performing products and sales trends.
- Create visualizations to present meaningful insights.

Task 1: Data Cleaning

- Transformed the dataset.

Task 4: Customer Segmentation

- Analyzed customer purchasing behaviour.
- Studied customer segments.
- Prepared customer segmentation results.

Task 5: Customer Insights

- Analyzed repeat customers.

Task 6: Data Visualization
